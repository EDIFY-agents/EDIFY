Docs · quickstart

From nothing to a verified change.

Four steps, one real task. About ten minutes. You need Python 3.10+ and a coding agent you already use.

01
Install the CLI

One package, zero runtime dependencies. uv tool install edify-cli works too.

pipx install edify-cli
02
Install the harness into a repository

Detects the stack, extracts the graph, scrapes conventions, installs the matching skills, writes a short CLAUDE.md, and records every file. Not on Claude Code? Use edify init new . to set up every runtime at once.

cd your-repository && edify init
03
Check the install

Green, amber or red, and exactly where. Amber means it works, degraded.

edify doctor
04
Run one real task in your agent

Write a short brief, then run the five commands in order. Read what the first three produce before moving on.

/spec → /plan → /tasks → /build → /verify
