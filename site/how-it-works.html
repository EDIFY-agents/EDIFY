Six commands you will actually type.

They run in your terminal, work offline, and print plain text or --json.
edify initDetects the stack, extracts the graph, records every file it put there.
edify doctorGreen, amber, red. Amber means it works, degraded, and names where.
edify graphwhere, dependents, defines, references, overlap. File and line.
edify checkWhat is wrong with the documents. --fix, --json, --exit-code.
edify governanceEvery installed file with its origin, licence and hash.
edify feedbackWrites a file on your machine. Nothing leaves on its own.

what EDIFY does not do
Wrap the agent runtime. Host a model. Run a server or a daemon. Enforce at runtime. Make a weak model competent.
It makes a competent model efficient.
