Why these limits

Each gate is where a team's need differs from a trial's.

Nothing working was removed to create a reason to pay.

25,000 nodes is roughly a 200–300k-line repository. Below it, EDIFY is genuinely optional. Above it is who the product is for.graph.unlimited
upgrade is the only asset with an ongoing cost: a human reads every library entry.library.upgrade
One server covers the default docs registry exactly. A second means internal systems.mcp.multi
Three projects separates trying EDIFY from working on it.projects.unlimited
Humans, not seats. The team plan caps people at ten and never counts agents. Add as many agents to the goal as the work needs.team
